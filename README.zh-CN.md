## 开源与 Pro

插件核心展示能力和全部既有显示设置保持开源。Pro 为一次性买断，仅绑定思源用户 ID，不绑定设备、不设使用期限；同一思源账号可在所有设备上使用。
首个 Pro 功能为数据库属性的行内编辑。（当然如果你有能力或者token可自行修改源码来绕过pro限制）
