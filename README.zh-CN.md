## 🔓 开源与 Pro

插件的核心展示能力及现有显示设置保持开源。项目通过云端 GitHub Actions 构建，构建过程透明，降低恶意代码注入风险。

Pro 为一次性买断制，仅绑定思源用户 ID，不绑定设备，也不设使用期限；同一思源账号可在所有设备上使用。


> Pro 功能用于支持项目的持续开发。核心展示功能不受影响，欢迎通过源码参与改进。
